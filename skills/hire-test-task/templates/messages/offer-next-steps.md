# Offer, next steps (to the finalist you are hiring)

Saved as `hiring/out/messages/<slug>-offer-next-steps.md`. The assistant never sends it.
Four short lines. Money and start date belong in a call, not in this message. The offer
letter itself is ready before that call: ask the `hire-first-month` skill "I'm about to make the
offer to [name]". This message only books the call where you say it out loud first.
The last line is for a paid task only. When the task was unpaid, leave it out; nothing replaces it.

---

Hi {first_name},

I read your {task, in two words} twice. I would like to work with you.

Can we talk {day} for 20 minutes to go over the role, the terms and a start date? Send me two times that work for you.

The {fee} for the task is on its way to you today, separately from all of this.

{signoff}
