# Offboarding: {name}

Written to `hiring/out/first-month/offboarding.md` on day one, before anyone needs it. The access plan is the list; this page is the routine. Twenty four hours from the decision to the written confirmation. The assistant writes this page; you do the clicks.

## The five steps, inside 24 hours

1. **Revoke every login.** Go down the table below, top to bottom, in one sitting. Seller Central first (Settings, User Permissions, delete the user; anyone with banking access would have been first, which is why nobody gets it). Then the mailbox: suspend, do not delete, so the mail is kept. Change any shared secret the person could have seen, even through the password manager.
2. **Remove from drives, repositories and admin panels.** Shared folders, the community roles, the ad accounts, any tool connected with their email. Check the password manager's access log for the last thirty days.
3. **Confirm deletion of local copies.** Ask for it in writing: files downloaded, exports, browser-saved passwords, chat history with customer data.
4. **Collect all work product.** The manual they wrote, open drafts, half-finished sheets, the login list of anything they set up. Move it into company drives before step 1 if you can plan the day; otherwise ask for it in step 4.
5. **Get written confirmation.** One reply from them covering steps 3 and 4; one note from you listing the date and time of steps 1 and 2. File both with the contract.

Pay what is owed to the day, on the normal rail, the same week. A withheld payment is the one thing that turns a clean exit into a dispute.
