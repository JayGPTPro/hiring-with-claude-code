# The first security conversation: {name}

Written to `hiring/out/first-month/phishing-talk.md`. Have this talk on day one, before the first login, on a call. Five lines, said out loud, then the written copy goes into the onboarding folder.

The documented way seller accounts get taken over is a phishing email at someone's end, not a permission set too wide. So the first security conversation is this one, and the permission grid comes second.

## The five lines

1. "Amazon, Google and our other tools never ask for your password by email or chat. If a message asks for one, it is fake, however real it looks."
2. "Before you type a password, read the address bar. If the address is not the one you know, close the tab."
3. "If something looks off, do not click. Forward it to me or paste a screenshot in our channel. Reporting a false alarm is always right; clicking is the only mistake."
4. "Every password lives in the password manager, in your own vault or a shared one. Nothing ever goes in WhatsApp, email or a chat message, from you or from me. If I ever send you one that way, tell me I broke my own rule."
5. "Two-step verification stays on an authenticator app on your phone, not SMS. If you change phones, tell me the day before."

## Then say this

"Asking for help is never punished here. If you are unsure whether something is safe, ask. I would rather answer ten questions than clean up one account."
